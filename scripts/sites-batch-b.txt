# Batch B — training sites, disjoint from batch A (the built-in list in
# generate_live_training_pairs.py) and from live_dom_mutation_eval.SITES.
#
# Site coverage is the measured lever: a model trained on 12 sites scored 90% on
# pages from those 12 and 18% on unseen ones. Batch A covered 150; this adds a
# second, non-overlapping set so a later run can compare 118 sites against ~300
# rather than against more samples from the same pages.
#
# Static, text-heavy, no ad rotation — content that changes between the baseline
# and current capture would corrupt the label.
